# kse-pm_password_manager

Корпоративний менеджер паролів для команди: централізоване зберігання доступів, sharing без пересилання паролів у чатах, audit log.

**Стек (MVP):** Spring Boot (Java) backend · Keycloak + Google Workspace SSO · PostgreSQL · WebAuthn/passkey як другий фактор · client-side encryption (сервер не зберігає відкриті паролі).
